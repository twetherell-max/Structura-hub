Tool Name Function Description Debate Use Case
Index Creator Uses AI to analyze selected text and automatically generates two types of summaries: a highly condensed "Technical" tag and a simple "Easy" summary, along with a source citation. Instantly create entries for your team's master index document without manual summarization, ensuring consistency and saving hours of work.
Advanced Card Condensing Extracts text between two user-defined markers (e.g., start of an article and a heading) and uses AI to condense it into a concise, two-sentence summary. Quickly shorten long pieces of evidence ("cards") to their core claim, making them easier to read and deploy in-round.
Card → Paragraph Tool Merges multiple selected paragraphs or list items into a single, clean paragraph, removing awkward line breaks while preserving formatting like bold and italics. Instantly clean up evidence copied from PDFs or websites that have messy formatting, making your documents readable and uniform.
Unique Tag Creator Inserts a short, user-defined title above the selected text, automatically styled as a unique heading (H6) for easy identification and navigation. Create consistent, machine-readable tags for every piece of evidence, which can then be used by other tools to generate a custom outline.
Custom Document Outline Scans the document for specific heading types (e.g., H1, H2, H6) and generates a clickable, in-sidebar table of contents for instant navigation. Jump directly to any card or section in a long, complex document (like a master file or block) without endless scrolling.
Link Checker (Refined) Scans every hyperlink in the document, verifies if it's active, and automatically highlights any broken or inaccessible links in red for immediate attention. Ensure the integrity of your evidence before a tournament by quickly identifying and fixing dead source links.
Label-Based Formatting Automatically applies a predefined set of formatting rules (e.g., font family, font size) to the entire document based on a keyword in the document's title (e.g., "POLICY"). Maintain perfect formatting consistency across all team documents without any manual effort, ensuring everyone's work is uniform.
Label-Based Sharing Moves the current Google Doc into a specific Google Drive folder and simultaneously shares it with a predefined list of editors based on a selected label. Automate document routing and permissions. Finish a file, select "Team Alpha Evidence," and the doc is instantly filed in the right folder and shared with the right people.
Auto-Citation Tool As part of the Index Creator, this AI-powered feature identifies the author's last name and year from the text to create a standardized citation (e.g., Smith '24). Eliminate the need to manually format citations for every piece of evidence, ensuring all your sources follow the same convention.
Manual Folder Move Provides a simple interface to move the current Google Doc into a designated Google Drive folder directly from the sidebar. Quickly organize your files into different project folders (e.g., "Affirmative," "Negative," "Impacts") without ever leaving the Google Docs interface.
