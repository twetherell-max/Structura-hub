Installation Guide

1. Open a Google Doc: Start in any Google Document where you want to use Structura.

2. Get Add-ons: Navigate to the menu and click Extensions > Add-ons > Get add-ons.

3. Find Structura: Use the search bar in the Google Workspace Marketplace to look for "Structura".

4. Install: Click on the Structura application from the search results and then click the "Install" button.

5. Grant Permissions: Follow the on-screen prompts to authorize the add-on. This is required for it to manage your documents and integrate with Google Drive.

API Key Setup (For AI Features)

To use the AI-powered features like the Index Creator and Card Condenser, you need to add your Gemini API key to the script properties. This is a one-time setup.

  1. Open your Google Doc's script editor by going to Extensions > Apps Script.
  2. In the script editor, click on the "Project Settings" (gear icon) on the left sidebar.
  3. Scroll down to the "Script Properties" section and click "Add script property".
  4. Enter GEMINI_API_KEY as the "Property" name.
  5. Paste your actual Gemini API key into the "Value" field.
  6. Click "Save script properties". The AI features will now be enabled.
